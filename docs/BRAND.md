# ARGUS visual identity

The active mark is `frontend/public/argus-mark.svg`: a compact lifecycle curve with a highlighted estimate. It uses the same squared panel geometry, line weight, and mint/lime palette as the interface. It deliberately avoids eye, pyramid, and orbital imagery.

Two retained explorations are available for future comparison:

- `frontend/public/brand/argus-mark-radar.svg` — monitoring and periodic scanning.
- `frontend/public/brand/argus-mark-nodes.svg` — weighted evidence connected into a signal.

All marks are original inline SVGs, legible at the 31-pixel header size, and contain no external assets.
